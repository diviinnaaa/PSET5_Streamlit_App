# PSET5 - Streamlit App

An interactive data visualization application created with Streamlit.

## Run locally

1. Install Python.
2. Open a terminal in this project folder.
3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Start the app:

   ```bash
   streamlit run app.py
   ```

## Features

- Dropdown to choose a bar, line, or pie chart
- Text input to customize the chart title
- Numeric inputs to change the displayed values
- Interactive visualization
- Data table and summary metrics
